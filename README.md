# Dungeon Meister

A 5E compatible solo engine where code resolves every rule.

**Status: in development.** Dungeon Meister 2.0 is a Rust rewrite of the original Python prototype. The legacy 1.x code is preserved at the [`v1.0.0`](https://github.com/verocai-vrc/DungeonMAIster/releases/tag/v1.0.0) tag.

## Build and test

```
cargo build
cargo test
```
